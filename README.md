# Mend

**Every crack has a story.**

Mend is a mixed reality experience for Meta Quest, built with the Immersive Web SDK. A box of broken keepsakes from a grandmother's house appears on your real table. You put each one back together with your bare hands. Every piece that clicks into place plays a memory from inside the object. Then you trace the cracks with liquid gold, in the spirit of kintsugi, and place the mended keepsake on a shelf that stays in your room.

One object a day. One family's story. The last bowl waits for a memory of your own.

- Built for the Meta VR Start Developer Competition 2026 (Entertainment, New Experience).
- Hands only, seated, no controllers.
- Runs in the Meta Quest Browser: no install needed.
